product · 2026 — in development

Project ACCURACY

Examination intelligence platform in development — 4,000 authored questions, zero dependencies.

Problem

Candidates preparing for the Telangana SI examination practise against question sets that repeat, that carry no worked explanations, and that give no signal about which concepts are actually costing marks. Commercial material is also online-only, which is a real constraint for candidates without reliable connectivity.

Approach

A content pipeline that authors questions from catalogued source material, audits the bank for near-duplicates before release, and compiles everything into a single self-contained HTML file that runs offline with no backend, no analytics and no third-party scripts. Student progress is stored locally and never transmitted.

  • JavaScript
  • HTML5
  • CSS3

  • Node.js
  • Standard library only

  • English coverage, at preliminary level.
  • The factual bank has had targeted review, not independent expert certification.
